# Keyboard and mouse

| Key / gesture         | Action                                                                       |
| --------------------- | ---------------------------------------------------------------------------- |
| **Ctrl/Cmd + K**      | Command palette: every server, resource, district and action                 |
| Click a building      | Fly there and open its panel                                                 |
| Click a district name | Frame the district and open its panel                                        |
| **Drag**              | Move across the city at the same zoom                                        |
| **Right-drag**        | Orbit (two fingers on a touchscreen)                                         |
| **Wheel**             | Zoom                                                                         |
| **Arrow keys**        | Pan                                                                          |
| **Tab / Shift+Tab**   | Next / previous building                                                     |
| **Esc**               | Close the innermost panel, stop ambient mode or replay, back to the overview |
| **Enter**             | Jack in: a terminal on the focused server                                    |
| **Ctrl+Shift+X**      | Leave the terminal                                                           |
| **D**                 | The Doctor (focused building, or everything)                                 |
| **T**                 | Time travel on / off                                                         |
| **R**                 | Runbooks (focused server, focused district, or any)                          |
| **H**                 | History (focused building, or every incident)                                |
| **E**                 | Edit the focused server or resource                                          |
| **A**                 | Ambient mode: tour what needs attention (for a second monitor)               |
| **`** (backtick)      | Performance overlay                                                          |

Also in the palette: lite mode (no bloom or particles for weak GPUs, suggested automatically when
frames are slow), the audit log, settings, importing from `~/.ssh/config`, and replaying the intro.
