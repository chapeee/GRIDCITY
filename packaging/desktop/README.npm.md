# gridcity-desktop

The [GRIDCITY](https://github.com/chapeee/GRIDCITY) desktop app: your servers, databases and
buckets as a living 3D city, in its own window with Chromium built in. No browser tab, no
terminal to keep open.

```bash
npx gridcity-desktop
```

- It runs the same server as the [`gridcity`](https://www.npmjs.com/package/gridcity) command
  and shares its data, settings and saved credentials. Use either, or both.
- Closing the window keeps GRIDCITY in the tray, still watching your servers and sending
  alerts. The tray menu can stop it.
- Prefer an installer? Download it for Windows, macOS or Linux from the
  [GitHub releases](https://github.com/chapeee/GRIDCITY/releases/latest).

Docs: <https://chapeee.github.io/GRIDCITY/docs/getting-started/desktop-app/>
